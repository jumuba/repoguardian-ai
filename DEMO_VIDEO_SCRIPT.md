# Demo video script

1. Open the landing page and explain the evidence-first review model.
2. Start the public demo without signing in to GitHub.
3. Show repository scores and select the command-injection finding.
4. Point out the exact file, line, excerpt, deterministic evidence, confidence, and correction.
5. Accept one finding, mark another false positive, and show the statistics update.
6. Export the reviewer-labelled result as JSON and Markdown.
7. Close on how reviewer decisions become evaluation data for AI coding training.
